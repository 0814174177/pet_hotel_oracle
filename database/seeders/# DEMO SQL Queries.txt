## 1. Kiểm tra số dòng các bảng chính

```sql
SELECT 'branch' AS table_name, COUNT(*) AS row_count FROM branch
UNION ALL SELECT 'type_room', COUNT(*) FROM type_room
UNION ALL SELECT 'room', COUNT(*) FROM room
UNION ALL SELECT 'users', COUNT(*) FROM users
UNION ALL SELECT 'customer', COUNT(*) FROM customer
UNION ALL SELECT 'pet', COUNT(*) FROM pet
UNION ALL SELECT 'employee', COUNT(*) FROM employee
UNION ALL SELECT 'services', COUNT(*) FROM services
UNION ALL SELECT 'product', COUNT(*) FROM product
UNION ALL SELECT 'branch_inventory', COUNT(*) FROM branch_inventory
UNION ALL SELECT 'booking', COUNT(*) FROM booking
UNION ALL SELECT 'booking_room', COUNT(*) FROM booking_room
UNION ALL SELECT 'booking_room_pet', COUNT(*) FROM booking_room_pet
UNION ALL SELECT 'booking_service_pet', COUNT(*) FROM booking_service_pet
UNION ALL SELECT 'orders', COUNT(*) FROM orders
UNION ALL SELECT 'order_details', COUNT(*) FROM order_details
UNION ALL SELECT 'payments', COUNT(*) FROM payments
ORDER BY table_name;
```

## 3. Loại phòng đúng với seed hiện tại

```sql
SELECT type_room_id, type_name, max_slot, pet_weight_min_kg, pet_weight_max_kg,
       base_price_per_day, is_active
FROM type_room
ORDER BY type_room_id;
```

Lưu ý: seed hiện tại dùng `Phòng nhỏ`, `Phòng vừa`, `Phòng lớn`; không dùng tên `Phòng tiêu chuẩn`.

## 4. Dịch vụ, gồm dịch vụ cho mèo

```sql
SELECT cs.service_category_name, s.service_id, s.service_name,
       s.species, s.base_price, s.duration_minutes, s.is_active
FROM services s
JOIN category_services cs ON cs.service_category_id = s.service_category_id
ORDER BY s.service_id;
```

## 5. Tỷ lệ hủy theo chi nhánh

```sql
SELECT b.branch_name,
       COUNT(*) AS total_booking,
       SUM(CASE WHEN bk.status = 'CANCELLED' THEN 1 ELSE 0 END) AS cancelled_booking,
       ROUND(100 * SUM(CASE WHEN bk.status = 'CANCELLED' THEN 1 ELSE 0 END) / COUNT(*), 2) AS cancel_rate_percent
FROM booking bk
JOIN branch b ON b.branch_id = bk.branch_id
GROUP BY b.branch_name
ORDER BY b.branch_name;
```

Kỳ vọng: quanh 4%, không còn chi nhánh nào bị hủy tới khoảng 20%.

## 6. Phân bố trạng thái booking

```sql
SELECT status, COUNT(*) AS total
FROM booking
GROUP BY status
ORDER BY status;
```

Kỳ vọng: phần lớn là `COMPLETED`/`CHECKED_OUT`; có một ít `PENDING`, `CONFIRMED`, `CHECKED_IN` để demo flow; `CANCELLED` thấp.

## 7. Booking active để demo phòng đang giữ

```sql
SELECT b.branch_name, bk.booking_id, bk.status,
       bk.checkin_expected_at, bk.checkout_expected_at,
       c.full_name AS customer_name
FROM booking bk
JOIN branch b ON b.branch_id = bk.branch_id
JOIN customer c ON c.customer_id = bk.customer_id
WHERE bk.status IN ('PENDING', 'CONFIRMED', 'CHECKED_IN')
ORDER BY bk.checkin_expected_at, bk.booking_id;
```

## 8. Kiểm tra room overlap cho trạng thái active

```sql
SELECT b.branch_name, tr.type_name, r.room_number,
       bk.booking_id, bk.status,
       bk.checkin_expected_at, bk.checkout_expected_at
FROM booking bk
JOIN booking_room br ON br.booking_id = bk.booking_id
JOIN room r ON r.room_id = br.room_id
JOIN type_room tr ON tr.type_room_id = r.type_room_id
JOIN branch b ON b.branch_id = bk.branch_id
WHERE bk.status IN ('PENDING', 'CONFIRMED', 'CHECKED_IN')
ORDER BY b.branch_id, r.room_number, bk.checkin_expected_at;
```

## 9. Kiểm tra booking hủy không tạo doanh thu ảo

```sql
SELECT o.order_id, o.booking_id, bk.status AS booking_status,
       o.status AS order_status, o.subtotal, o.discount_amount, o.grand_total,
       p.status AS payment_status, p.amount
FROM orders o
JOIN booking bk ON bk.booking_id = o.booking_id
JOIN payments p ON p.order_id = o.order_id
WHERE bk.status = 'CANCELLED'
ORDER BY o.order_id
FETCH FIRST 20 ROWS ONLY;
```

Kỳ vọng: `subtotal = 0`, `grand_total = 0`, `payment.amount` lưu số tiền attempt dương, `payment.status = FAILED`.

## 10. Kiểm tra multi-pet room

```sql
SELECT br.booking_room_id, br.booking_id, r.room_number,
       COUNT(brp.pet_id) AS pet_count
FROM booking_room br
JOIN room r ON r.room_id = br.room_id
JOIN booking_room_pet brp ON brp.booking_room_id = br.booking_room_id
GROUP BY br.booking_room_id, br.booking_id, r.room_number
HAVING COUNT(brp.pet_id) >= 2
ORDER BY br.booking_room_id;
```

## 11. Kiểm tra booking không trước ngày customer tạo

```sql
SELECT COUNT(*) AS invalid_booking_count
FROM booking bk
JOIN customer c ON c.customer_id = bk.customer_id
WHERE bk.created_at < c.created_at;
```

Kỳ vọng: `0`.
